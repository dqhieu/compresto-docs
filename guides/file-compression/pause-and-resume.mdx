## Overview

You can pause a running batch at any time, for example when you need your Mac's full power for something else, and resume it later. Pausing works for every file type.

## Pause a Batch

While compression is running, press the pause button next to the progress bar (**Pause after current file**).

Compresto finishes the file it's working on, then stops. The status shows **Pausing after current file...** until that file is done.

## Resume

When paused, press **Resume** to continue. The button shows how many files are left, for example **Resume (3 files)**. Compresto picks up from the first file that hasn't been compressed yet.

## Cancel

Press the **Cancel all** button (the X next to pause) to stop the batch entirely. It's available both while compressing and while paused.

<Tip>
Want to limit how much of your Mac compression uses without pausing? Try the [CPU cores limit](/customization/cpu-cores-limit).
</Tip>
