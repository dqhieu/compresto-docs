`compresto` is the command-line version of Compresto. It runs on its own, so the Mac app doesn't need to be open, which makes it a good fit for scripts, automation and batch jobs.

```bash
compresto movie.mov
# ✓ movie.mov → movie_compressed.mov  48.2 MB → 9.1 MB (−81%)  12.3s
```

<Note>
The command-line tool is for macOS and needs a Compresto license, the same one you use for the Mac app. Setapp licenses can't be used with it.
</Note>

## Quick start

```bash
brew install dqhieu/tap/compresto
compresto auth login
compresto movie.mov
```

## What's different from the Mac app

The command-line tool uses the same quality levels as the app and produces comparable results. A few things are only in the app for now:

- EPUB and SVG files
- Keeping image metadata
- Videos with transparency
- Presets, folder monitoring and the other workflow features
