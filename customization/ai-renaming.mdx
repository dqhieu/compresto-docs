## Overview

AI renaming uses a vision model to analyze your compressed images and generate descriptive file names automatically. You can use OpenAI in the cloud, or run a local model with [Ollama](https://ollama.com) so nothing leaves your Mac. Instead of keeping generic names like `IMG_0042.jpg`, Compresto can rename files based on their visual content — e.g., `sunset-over-mountain-lake.jpg`.

<Note>
AI renaming is currently available for **images only**. Video, GIF, and PDF files are not supported yet.
</Note>

## Choose a Provider

| Provider | Runs on | Needs |
|----------|---------|-------|
| **OpenAI** | OpenAI's servers | An OpenAI API key; billed per image |
| **Ollama (Local)** | Your Mac | Ollama installed with a vision model; free and offline |

## Setup with OpenAI

<Steps>
  <Step>
    Open **Settings** > **AI Renaming** and turn on **Enable AI Renaming**
  </Step>
  <Step>
    Set **Provider** to **OpenAI**
  </Step>
  <Step>
    Enter your **API Key** and press **Verify**

    You can get an API key from [platform.openai.com](https://platform.openai.com/api-keys). The key is stored securely in your Keychain.
  </Step>
  <Step>
    Choose a **Model**
  </Step>
  <Step>
    Select a **naming style** and compress your images — files will be renamed automatically
  </Step>
</Steps>

## Setup with Ollama (offline)

<Steps>
  <Step>
    Install [Ollama](https://ollama.com) and pull a vision model, for example:
    ```bash
    ollama pull llava
    ```
  </Step>
  <Step>
    Open **Settings** > **AI Renaming** and turn on **Enable AI Renaming**
  </Step>
  <Step>
    Set **Provider** to **Ollama (Local)**
  </Step>
  <Step>
    Check the server URL (default `http://localhost:11434`) and press **Test**
  </Step>
  <Step>
    Choose a **Model**. Compresto lists the vision models installed in Ollama; press the refresh button after pulling a new one.
  </Step>
</Steps>

<Note>
If the model list shows **No models found**, make sure Ollama is running and that you've pulled a vision-capable model. If no model is selected, files are compressed but not renamed.
</Note>

## OpenAI Models

| Model | Speed | Cost | Best For |
|-------|-------|------|----------|
| **GPT-5 Nano** (default) | Fastest | Lowest | Quick batch renaming |
| **GPT-5 Mini** | Fast | Low | Everyday use |
| **GPT-5** | Moderate | Medium | Detailed descriptions |
| **GPT-5.1** | Slower | Higher | High accuracy |
| **GPT-5.2** | Slowest | Highest | Maximum accuracy |

<Note>
Faster models cost less per image but may produce less detailed names. For most users, **GPT-5 Mini** offers the best balance of speed and quality.
</Note>

## Naming Style

| Preset | Example Output | Description |
|--------|---------------|-------------|
| **Descriptive** | `golden-retriever-playing-in-park` | Detailed description of the image content |
| **SEO Friendly** | `cute-dog-park-outdoor-photography` | Optimized for search engines with relevant keywords |
| **Short** | `dog-park` | Brief, concise file names |
| **Technical** | `canine-outdoor-natural-lighting-wide-angle` | Technical photography terminology |
| **Custom** | *(your prompt)* | Define your own naming rules |

### Custom Prompt

When using the **Custom** preset, you can write your own prompt to control how files are named. For example:

- `"Name the file based on the dominant color and subject"`
- `"Use product category followed by a brief description"`
- `"Generate a name suitable for an e-commerce product listing"`

## Max Filename Length

Use the **Max filename length** slider (20–200 characters) to keep generated file names manageable. This prevents overly long names that can cause issues with some file systems or workflows.

## Rename in the Notch

After compressing a single file, you can rename the output yourself right from the notch: click the pencil icon next to the file name, type a new name, and press **Return**. Press **Esc** to cancel. The file extension can't be changed, and the notch stays open while you type.

The notch also shows AI renaming progress after compression finishes.

## Tips

- **Batch processing**: AI renaming works with batch compression — all images in a batch are renamed individually
- **API costs**: With OpenAI, each image requires one API call. Monitor your usage for large batches, or switch to Ollama for free on-device renaming
- **Privacy**: Images are downscaled before analysis. With Ollama, nothing is sent to a server
- **Custom prompts**: Be specific in custom prompts for more consistent results
- **File extension**: The original file extension is always preserved regardless of the generated name
