## Overview

Compresto is available in six languages. By default it follows your macOS language.

## Supported Languages

| Language | Shown as |
|----------|----------|
| System default | System |
| English | English |
| German | Deutsch |
| Spanish | Español |
| French | Français |
| Brazilian Portuguese | Português (Brasil) |
| Simplified Chinese | 简体中文 |

## How to Change the Language

<Steps>
  <Step>
    Open **Settings** > **General**
  </Step>
  <Step>
    Choose a language from the **Language** picker
  </Step>
  <Step>
    Press **Restart** when asked. Compresto quits and reopens in the new language.
  </Step>
</Steps>

You can also pick a language on the welcome screen the first time you open Compresto.

<Note>
Choose **Later** to keep working. The new language is applied the next time Compresto launches.
</Note>
